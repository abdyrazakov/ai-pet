# Демо-видео

Здесь будет финальное видео проекта (план: 1–2 минуты).

## Сценарий

1. Питомец стоит на столе, моргает (IDLE)
2. Касание → уши поднимаются, эмоция на экране (WAKE)
3. Голосовой вопрос («Что такое фотовольтаика?») → LISTENING → THINKING
4. Питомец отвечает голосом, уши двигаются (SPEAKING)
5. Поглаживание → счастливая эмоция (PETTING)
