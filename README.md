# AI-Питомец «Ассистент»

Интерактивный настольный AI-питомец на базе ESP32: голосовой помощник + механическая анимация (подвижные ушки) + эмоции на OLED-дисплее.

## Идея

Питомец стоит на столе, «живёт» (мордочка на экране, ушки в расслабленном положении). Пользователь касается сенсора или говорит — питомец оживает: ушки двигаются, на экране меняется эмоция, после обработки вопроса через AI-сервис он отвечает голосом.

## Функции

- **Развлечение**: компаньон для стола, поддерживает беседу, шутит
- **Образование**: ответы на вопросы, напоминания, переводы
- **Интерактивность**: реакция на касание и голос, эффект присутствия живого существа

## Архитектура

| Блок | Компоненты | Назначение |
|------|-----------|------------|
| Мозг | ESP32 | Wi-Fi, обработка запросов, управление периферией |
| Аудио | INMP441 (микрофон) + MAX98357 (усилитель) + динамик | приём и воспроизведение речи |
| Моторика | Сервоприводы | движение ушек (эмоциональный отклик) |
| Интерфейс | OLED 0.91" + TTP223 (касание) / кнопки | глаза, состояния, тактильный ввод |

## Структура репозитория

- `code/` — прошивка ESP32 (PlatformIO / Arduino)
- `schema/` — схема подключения компонентов
- `state-machine/` — конечный автомат состояний питомца
- `video/` — демо-видео проекта
- `budget/` — смета на компоненты
